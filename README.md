## 📌 About the Project

A **Modern Restaurant Workflow System** developed as a personal project to practice full-stack web development, database design, and business process implementation.

Qitchen streamlines restaurant operations by integrating customer ordering, cashier management, kitchen workflow, delivery tracking, voucher management, referral programs, and administrative management into a single platform.

---

## ✨ Key Features

* 👤 Multi-role authentication (Member, Cashier, Kitchen, Courier, Admin)
* 🍔 Digital menu and category management
* 🛒 Cart and checkout system
* 💳 Online payment integration
* 🎟️ Voucher and referral system
* 🍳 Kitchen workflow management
* 📺 Order display board
* 🚚 Delivery management and tracking
* 📰 Article and content management
* 📊 Sales and operational dashboard
* 📱 Responsive mobile-friendly interface
